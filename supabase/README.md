- `migrations/` — schema, RLS, `bc_*` functions (apply in order).
- `seed/venue_tables.sql` — table codes, generated by `docs/venue/qr/make_qr.py` (rerun after `--rotate <table>`).
- `functions/verb/` — Edge Function: records a verb (as the player) and sends the Web Push; makes the VAPID keys on
  first run (kept in `private.vapid`, never in git). Deploy with **verify_jwt off** (CORS preflight).
- Anonymous sign-ins must be on (Authentication → Sign In / Providers → "Allow anonymous sign-ins").

Test switches (server only, SQL editor): `update bc_settings set ignore_hours = true` (check-ins outside 19–02),
push caps in the same row (`push_max_per_night`, `push_per_sender`, `push_from_hour`, `push_until_hour`).
Reprint one table's code: `python docs/venue/qr/make_qr.py --rotate Table3`, then run `seed/venue_tables.sql`.
Moderation: `reports` table (status open/kept/dismissed/banned), `profiles.banned`, `profiles.name_hidden`.
