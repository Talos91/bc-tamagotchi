## mg_rivals API (for Q5-Q9; full doc at the top of `game/scripts/minigames/mg_rivals.gd`)
```
const Rivals = preload("res://scripts/minigames/mg_rivals.gd")
# _on_start
var t := Rivals.tonight(game_id)       # {night, best, ghost, rival, board}
rival = t.rival                        # {regular, name, points}: the next rung above your best tonight
ghost = t.ghost                        # {} or what you passed to record() with your best run tonight
# _result_extra (runs once, from finish())
var r := Rivals.record(game_id, points_for(score), my_ghost_dict)
return {..., "rival": rival, "board": r.board_line}   # result_card shows "You beat Jules (90)" + "#2 of 5 tonight"
```

## Gotchas
- When the game script fails to compile, `test_neon_moth` still exits 0 with "PASS": every test call errors at
  runtime before any check() runs, so failures stay 0. Read the log for SCRIPT ERROR and the check count, not only
  the last line (this job's first run hit exactly that). test_neon_moth now fails below 100 checks; other suites lack the guard.
- `:=` on a Dictionary value fails to compile ("Cannot infer the type"): type those vars.
- Lambdas copy captured locals: `func(r): result = r` does not reach the outer var; merge into a Dictionary.
- Drawing must not create the fx overlay (`_fx_ok()` guard): `fx()` adds a child.
- Glow layer: a child Control with `Fx.glow_material()` (additive), drawn through its `draw` signal, placed under the
  fx overlay.
