# handoffs/

One note per task lives here: what was done, what is open, what the next session must know. Each note is written by the
worker (or orchestrator) that ends the task, named `<role>-<date>.md`, and compressed to "state now" rather than a diary.

A note is archived (moved to `handoffs/archive/`) after the release that ships its task. Until then it is the first thing a
replacement session reads after `PROJECT.md` and `STATE.md`.
