- venue.tscn is generated by game/tools/build_venue.gd from manifest.json; re-run it after kit re-exports.
  A kit object named `banquette` will replace the box banquettes automatically.
- Bar moved to the SOUTH wall, communal table + banquette on the north wall, so the entrance view matches R01.
- project.godot: hdr_2d=true, stretch aspect "expand" (was "keep"), navigation cell 0.1/0.05, max lights 48.
  UI sessions: with "expand" the visible rect is wider/taller than 1080x1920 on other aspect ratios; anchor to edges.
- Camera rig (scripts/camera_rig.gd) hides render layer 2; anything that should only show at eye level goes there.
- Player API for other systems: Player.walk_to(world_pos), Player.tap_at(screen_pos), Player.rig.zone.
- Kit cost: floor view = ~1100 draw calls (objects have 2-9 material surfaces). Kit pipeline should merge
  surfaces / atlas materials before mobile. Curtain (7.7k tris) and backdrop (9.8k) are the heaviest repeated pieces.
- Compatibility gives no floor reflections: the glossy floor only shows specular dots. A reflection probe or a
  faked reflection pass is the next step to get R02's red floor streaks.
