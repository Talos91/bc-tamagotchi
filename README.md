# Black Cabin Tamagotchi

A cozy voxel social game that recreates the real Bangkok live-music bar
**Black Cabin** as a persistent venue. Your character has a weekly need for
music, friends, drinks and nightlife; you refill it by visiting the bar,
meeting regulars, catching performances and playing short bar-culture
minigames.
